# Changelog

All notable changes to this project are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v2.10]

### Added
- DVLA letter: a new section explaining that anyone using a deed poll or statutory declaration must also send one additional document showing their new name, with a dropdown to select and insert the specific document being sent (12-months-or-newer options, plus no-time-limit alternatives).
- A floating version/GitHub badge in the bottom-right corner, showing the current version and linking to the [source repository](https://github.com/MichelleFindlay/tig-namechange). Hidden when printing.

### Changed
- Footer credit now reads "GPL 3.0" in place of "Made with pride".

### Fixed
- Corrected wording and duplication issues in the DVLA supporting-document dropdown (stray repeated text, a garbled government/council option).
- Fixed a wording error on the Passport step.

## Earlier history

- Improved small-screen responsiveness, pinned the logo, and made the ring fit 1920x1080 without scrolling.
- Added a printable checklist with confetti celebration, plus a Qualifications & Degrees step.
- Added an Electoral Roll (council) step to the ring.
- Added a printable GP supporting-letter guide under the Passport step.
- Made Reset fully restore first-load state, not just clear fields.
- Turned DVLA free-text fields into dropdowns, fixed print spacing/underlines, and defaulted the deed poll date to today.
- Added the Trans in Gloucestershire logo to the header and stripped print colour styling.
- Replaced typed signature fields with blank ink-signature spaces and added A4 print support for the deed poll.
- Removed completion tracking and the progress bar; added a reset-fields button.
- v1.1 / v1.2 — early iterations of the name-change journey ring and forms.
- Initial commit.
